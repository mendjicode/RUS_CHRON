# Хроники России

Локальное приложение для изучения истории России от древности до современности. Без аккаунта и собственного сервера. Существующие дизайн, архитектура и идентификаторы сохранений сохранены.

**Состояние на 13 ноября 2026:** Уроки: 291/291; задания: 1151; понятия: 99; биографии: 55; хронологические записи: 711. Объём основного текста (слов): 160 584, без простого/углублённого режимов и упражнений.

Все материалы имеют статус «написан»: выборочная сверка источников и технические проверки выполнены, полная построчная научная и методическая редактура не завершена. Наличие ссылки не выдаётся за подтверждение каждой фразы. Основной современный разбор опирается на февральские документы 2026 года; последнее отдельно датированное дополнение — 2026-11-09. Дата обновления приложения не расширяет охват каждого источника.

## Запуск

Требуется Node.js 22.12+ и npm. В существующей папке проекта:

```sh
npm install
npm run dev
```

Откройте адрес Vite, обычно http://localhost:5173. Для производственной версии: `npm run build`, затем `npm run preview`. В браузере дождитесь «Автономный режим готов»; после этого уроки и локальные ресурсы доступны без сети. Внешняя литература открывается по сети.

## Курс и обучение

- Все темы (291) имеют собственные тексты, три содержательных уровня, цели, даты, резюме, источники и задания; 38 смысловых модулей объединяют темы.
- Девять видов заданий: выбор, несколько ответов, хронология, соответствия, причины, пропуск, география, документ, свободный ответ. Свободные ответы и открытые причинные вопросы сохраняются как самооценка. Итог эпохи собирает до 20 вопросов из разных уроков.
- Интервальное повторение, история ответов, время, достижения и прогресс по реальным действиям. Можно открывать уроки в любом порядке.
- Заметки, закладки уроков, избранные события, факт дня, поиск; 99 терминов, 55 персоналий, 15 сопоставлений Россия–мир.
- Отдельные позиции чтения для трёх уровней, размер текста, режим чтения, светлая/тёмная/системная темы. Ctrl/⌘+K открывает поиск, Esc закрывает карточки.
- Семь подлинных локальных карт с границами/направлениями, зумом и перемещением; 3 пошаговых сценария с 12 этапами. Происхождение и ограничения каждого листа видны в атласе.
- Учебные сравнения, схема событий 1991 года, фрагменты родословных; три исторических портрета и архивная фотография с атрибуцией.

Прогресс хранится на устройстве в IndexedDB. В настройках можно экспортировать/импортировать JSON-копию; копии v1 предыдущей версии поддерживаются. Браузер и Windows-приложение имеют отдельные хранилища.

# Хроники России

Локальное приложение для изучения истории России: учебные тексты, упражнения, интервальное повторение, географический атлас, хронология и справочники. Без аккаунта и собственного сервера.

## Быстрый запуск на Windows, macOS или Linux

Требуется Node.js 22.12+ (рекомендуется актуальная LTS) и npm.

```sh
git clone https://github.com/mendjicode/RUS_CHRON.git
cd RUS_CHRON
npm install
npm run dev
```

Откройте адрес, напечатанный Vite, обычно `http://localhost:5173`. Аккаунт не нужен. Первая установка зависимостей требует интернета. Для разработки Vite должен продолжать работать.

## Возможности этой версии

- Каталог всей программы с отдельным статусом каждого урока; запланированные темы не притворяются написанными.
- Уроки с простым, подробным и углублённым режимами, опорными датами, источниками, резюме и заданиями.
- Проверка одного/нескольких ответов, порядка, соответствий, причин, географического контекста и критики источников. Свободные ответы — явная самооценка.
- Интервальное повторение: 1, 3 и последующие дни для успешных ответов; 10 минут после ошибки.
- IndexedDB: прогресс, закладки, заметки, место чтения, история, активное время и настройки.
- Экспорт/импорт резервной копии с валидацией. Очистка браузера удаляет локальные данные — сохраняйте копии.
- 43 термина, 24 краткие биографические справки, хронология из написанных материалов.
- Атлас на настоящей основе Natural Earth: масштабирование, перемещение, эпохи, маркеры, связанные уроки. Исторических границ и маршрутов войск пока нет.
- Светлая, тёмная и системная темы; размер текста, режим чтения, адаптивная навигация, поиск по названию, понятию, личности и дате.

## Производственная сборка и офлайн

```sh
npm run build
npm run preview
```

Сборка находится в `dist/`. Открывайте её через локальный HTTP-сервер или Electron, а не двойным щелчком по HTML.

В браузере Service Worker кэширует ресурсы после первого успешного открытия производственной сборки. Дождитесь надписи «Автономный режим готов» в боковой панели. В режиме разработки автономный кэш не включается. Внешние источники требуют сети; сами уроки, шрифты, изображение и карта локальны.

В Electron вся библиотека поставляется вместе с приложением и не нуждается в первом сетевом открытии. Прогресс браузера и Electron хранится раздельно; переносите его через JSON-копию.

## Windows: установка и `.exe`

```sh
npm run desktop
npm run dist:win
```

`desktop` собирает приложение и запускает Electron. `dist:win` создаёт NSIS-установщик в `release/`. Выполняйте сборку на Windows: кросс-сборка Linux не является проверенной заменой. Подробности — [docs/WINDOWS.md](docs/WINDOWS.md).

Workflow **Windows installer** в GitHub Actions запускается вручную и после успешного CI для `main`. Он собирает `.exe` и сохраняет его как артефакт `rus-chron-windows`. Настройка workflow не означает, что его запуск уже успешно завершён. Проверяйте состояние конкретного запуска.

Установщик не подписан коммерческим сертификатом. Цифровая подпись и проверка установки на чистой Windows остаются отдельными задачами.

## Проверки

```sh
npm run validate:content
npm test
npm run check
npm run verify:dist
npm run docs:content
```

`check`: структура → тесты → TypeScript и Vite. `verify:dist`: проверка ссылок локальных ресурсов и списка офлайн-кэша уже собранного приложения. Тесты включают IndexedDB через fake-indexeddb, React SSR и взаимодействия в jsdom; они не заменяют реальный браузер и Windows.

Для облачной среды с доступной только веб-разработкой можно установить зависимости с `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci`; это пропускает скачивание Electron и не позволяет запускать desktop без последующей установки бинарного файла. На обычной Windows используйте стандартный `npm install`.
