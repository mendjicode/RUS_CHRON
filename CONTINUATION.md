# Как продолжить без повторной сборки проекта с нуля

1. Прочитать AGENTS.md, docs/BRIEF.md, CONTENT_STATUS.md, SOURCES.md и TODO.md.
2. Выполнить `npm ci` и `npm run check`. Если нужен только web в ограниченной среде, разрешается пропустить скачивание бинарника Electron согласно README.
3. Не переписывать работающие разделы ради нового каркаса. Данные пользователя и формат backup v1 сохранить.
4. Основная оставшаяся работа — настоящий учебник: 270 тем ещё не написаны. Продолжить с `01-002` «Исторические источники», затем `01-003` и далее. Уже написанные уроки не создавать повторно. На каждую эпоху должны приходиться содержательные уникальные тексты, а не автоматическая подстановка названий.
5. Для очередной темы проверить программу и источники, уточнить цель, описать собственный материал, добавить реальные связи, даты и упражнения. Создать `src/content/lessons/<ID>.json` по Zod-схеме. Новый текст первоначально `written`.
6. Подготовить ведомость проверки утверждений. Только после проверки фактов и источников повышать до `checked`; методическая и техническая проверка нужны для `ready`.
7. Выполнить `npm run docs:content`, обновить программу и TODO по факту, затем `npm run check` и `npm run verify:dist`.
8. Выполнить доступные настоящие браузерные проверки. SSR/jsdom уже есть, но это не проверка реального Service Worker и рендеринга Chrome. На Windows проверить установщик и восстановление данных.
9. Коммитить и отправлять в mendjicode/RUS_CHRON обычным fast-forward; не перезаписывать чужие изменения force-push.

## Точки внимания

- Атлас не содержит исторических границ и маршрутов. Добавление точек не должно превращаться в вымышленную реконструкцию.
- В программе пока технические номера модулей и общие формулировки некоторых результатов. Нужна отдельная методическая работа по каждому уроку.
- Уроки, справки и словарь не прошли полную научную редактуру; доступная ссылка не доказывает каждую фразу.
- Документы современной войны использованы до 16 февраля 2026 года. Не выдавать это за актуальную сводку на любую более позднюю дату.
- Офлайн в браузере требует первого успешного кэширования production-сборки; в Electron учебные ресурсы поставляются локально.
