# Windows: полный курс —13 ноября2026

Все291урок и локальные ресурсы включены в ту же Electron-сборку. Для обычной разработки наWindows: Node.js22.12+; затем `npm install`, `npm run desktop`. Установщик: `npm run dist:win`, результат в `release/`. Используется собственный значок из `build/icon.ico`.

Workflow **Windows installer** запускается после успешного **Quality checks** для`main` или вручную. Он выполняет:

1. `npm ci`, сборкуTypeScript/Vite иNSIS без публикации релиза (`--publish never`).
2. Проверку локальных ресурсов/офлайн-кэша.
3. Настоящую тихую установкуNSIS во временный каталогWindows-исполнителя.
4. Запуск установленного `.exe` с`--smoke-test` в отдельном новом профиле: главная, урок, запись заметки, перезагрузка и восстановление, открытие полного исторического листа в безопасном окне.
5. Загрузку установщика как артефакта`rus-chron-windows` и отчёта`rus-chron-windows-checks`.

Откройте [GitHub Actions](https://github.com/mendjicode/RUS_CHRON/actions), выберите успешный **Windows installer**, внизу **Artifacts** скачайте`rus-chron-windows`, распакуйтеZIP и запустите`.exe`. Артефакты хранятся14дней; позднее можно запустить workflow повторно. Загрузка артефакта может потребовать входа вGitHub.

Приложение запускается без аккаунта и сети. Для переноса прогресса из браузера экспортируйтеJSON вНастройках и импортируйте его вWindows-приложение. Профили браузера иElectron независимы.

Установщик не подписан коммерческим сертификатом. Автоматическая установка/запуск не заменяют независимую ручную оценку на всех устройствах. Результат конкретного финального запуска записывается в `docs/QA.md` и журнале задачи; настройка workflow сама по себе не объявляется пройденной проверкой.

# Сборка Windows-приложения

## На компьютере с Windows

1. Установить Node.js LTS (не ниже 22.12).
2. Клонировать репозиторий и выполнить `npm install`.
3. Выполнить `npm run check`.
4. Для проверки приложения — `npm run desktop`.
5. Для установщика — `npm run dist:win`.

NSIS `.exe` и служебные файлы появляются в `release/`. Имя включает «Хроники России» и версию из package.json. Установщик позволяет выбрать каталог и создать ярлык. Основные материалы входят в asar и не требуют сервера.

## Через GitHub Actions

Workflow **Windows installer** запускается через Actions → Windows installer → Run workflow либо после успешного **Quality checks** для main. Откройте завершённый запуск и скачайте ZIP-артефакт `rus-chron-windows`; внутри находится установщик `.exe`.

Сборка в CI подтверждает создание пакета, но не заменяет ручную установку и учебную сессию на чистой Windows. Подпись установщика не настроена. Нельзя утверждать, что ручной тест пройден, если проверена только упаковка.

## Контрольный сценарий

- Установить приложение в каталог с кириллицей.
- Запустить без сети, открыть все разделы и несколько уроков.
- Изменить тему и размер текста, добавить заметку и закладку.
- Ответить на задания, закрыть окно, снова запустить и проверить восстановление.
- Экспортировать копию, импортировать её в другой профиль и сравнить данные.
- Проверить внешнюю HTTPS-ссылку: открывается системный браузер, не окно с Node.js.
- Проверить масштабирование карты, навигацию клавиатурой, дисплеи 100/125/150%.
- Удалить приложение; отдельно проверить, какие пользовательские данные сохраняет профиль Electron.

## Если Electron не скачивается

Установка оболочки требует доступа к официальным GitHub Releases Electron. В корпоративной сети настройте документированный прокси для `@electron/get`. Не отключайте проверку TLS.

Для работы только с веб-частью можно использовать `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm ci` в оболочке, поддерживающей такую запись, или `$env:ELECTRON_SKIP_BINARY_DOWNLOAD='1'; npm ci` в PowerShell. Затем перед desktop-сборкой удалите эту переменную и выполните `npm rebuild electron`. Обычная установка на Windows не нуждается в этих настройках.
