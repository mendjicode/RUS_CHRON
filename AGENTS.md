# Работа над «Хрониками России»

Этот файл добавлен при создании проекта: в исходном репозитории был только README.md.

## Перед изменениями

Прочитать `docs/BRIEF.md`, `CURRICULUM.md`, `CONTENT_STATUS.md` и `TODO.md`. Существующие пользовательские данные и работающие страницы сохранять. При возобновлении начать с `CONTINUATION.md`.

## Продукт

- React, TypeScript, Vite; локальная работа без аккаунта и собственного сервера.
- Контент, шрифты, изображения и географическая основа должны входить в сборку.
- Прогресс хранить в IndexedDB. Изменение формата требует миграции и проверки импорта старых копий.
- Пользовательские тексты выводить как текст; не применять `dangerouslySetInnerHTML`.
- Windows-оболочка: изоляция контекста, sandbox, без Node.js в renderer.

## Содержание

- Уроки добавлять в `src/content/lessons/<ID>.json`, отдельно от React.
- ID и названия брать из программы. Новые необходимые темы сначала включать в программу.
- Соблюдать Zod-схему и проверять связи с персоналиями, словарём, местами и источниками.
- Не генерировать однотипные уроки для количества. Каждый материал имеет собственные объяснения и задания.
- Не повышать `written` до `checked` без документированной проверки утверждений. `ready` также требует методической проверки.
- Не считать доступную библиографическую карточку прочитанной монографией.
- Не придумывать цитаты, источники, числа потерь, исторические границы и маршруты. Для реконструкций указывать основания и точность.
- У современных событий указывать дату актуальности и отличать факт от официальной позиции и интерпретации.
- Обновлять `CONTENT_STATUS.md` командой `npm run docs:content`, а программу и план продолжения — по существу изменений.

## Проверки

`npm run check` выполняет проверку структуры, тесты и производственную сборку. После изменения PWA дополнительно `npm run verify:dist`.

Не называть SSR или jsdom настоящей браузерной проверкой. Сборку `.exe` проверять на Windows через `npm run dist:win` или GitHub Actions; наличие конфигурации само по себе не подтверждает работоспособность установщика.
